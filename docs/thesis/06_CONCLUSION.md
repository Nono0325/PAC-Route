# 第六章 結論與未來展望 (Conclusion & Future Work)

本章將對本碩士論文之核心研究成果進行系統性總結，並探討 PAC-Route 在分散式邊緣運算與隱私保護領域之長期發展潛力與未來研究延伸方向。

---

## 6.1 研究結論總結

本論文針對個人與邊緣實驗室在多代理自主工作流興起背景下，由多台異質硬體（高階 RTX 工作站、個人 PC、單板電腦等）組建個人 AI 推論叢集時所面臨的「隱私外洩盲區」、「SLA 違約頻仍」以及「轉發層尾端延遲過高」三大痛點，成功研發並實作了基於系統程式語言 **Rust** 之開源調度系統——**PAC-Route**。

本研究之主要研究成果如下：
1. **確立去中心化兩平面安全隔離理論**：
   嚴格劃分「隱私授權外部平面」與「本地推理平面」，從架構本質上消除了傳統二元路由將歷史上下文直接上傳至雲端的風險，達成了「無授權絕不出網」的零信任保證。
2. **提出整合 SLA 動作遮罩之 Dueling DDQN 排程演算法**：
   建立端到端延遲拆解預測模型，並在強化學習動作選取時導入即時動作遮罩機制。在實體異質測試集上，將任務之 SLA 截止期限逾期率（Deadline Miss Rate）由同質基準的 34.6% 驟降至 **4.0%**，降幅高達 **82.4%**。
3. **實現動態軟體閘門與雙層 LDP 語義草圖協同管線**：
   捨棄硬性非黑即白決策，以實體層級之雙層差分隱私對敏感數據進行擾動，由雲端生成抽象語義草圖、邊緣端無失真還原，在確保資料外洩率為 0.0% 的同時，維持了高達 94.8% 之語義品質。
4. **構建全 Rust 高併發低延遲生產級系統**：
   藉由 Tokio 非同步非阻塞框架與 UDP 局域網節點自動發現協定，系統無縫向下相容 OpenAI 與 Ollama API，並將極限 P99 尾端延遲壓縮了 61.4%，證明了 Rust 在新世代 AI 路由基礎設施中的極高工程實用性。

## 6.2 未來研究方向 (Future Work)

儘管 PAC-Route 在異質個人叢集的即時推論調度上展現出卓越效能，但在未來仍有以下極具研究價值之擴展方向：

### 1. 結合分散式 LoRA 增量微調與記憶共享 (Federated/Distributed LoRA)
目前的 PAC-Route 著重於**推論（Inference）階段**的路由分配。未來可將兩平面架構擴展至**模型微調（Fine-tuning）階段**。在隱私授權訓練平面中，利用聯邦學習（Federated Learning）或分散式 LoRA，讓各個個人異質節點在保護本地資料的前提下協同微調專屬小型模型，進一步提升語義草圖在特定專業領域的還原精度。

### 2. 硬體可信執行環境 (TEE) 與機密運算結合
在雲邊協同模式中，未來可探索利用硬體可信執行環境（Trusted Execution Environment, TEE，如 AMD SEV-SNP、Intel TDX 或 NVIDIA Hopper 機密計算 GPU）。在將語義草圖發送至雲端時，直接將計算封裝至遠端飛地（Enclave）中，以密碼學硬體層級徹底杜絕雲端服務商或惡意第三方的記憶體側通道攻擊（Side-Channel Attacks）。

### 3. 跨網段多叢集 Mesh 拓撲與動態頻寬感知
目前的發現與協同主要聚焦於單一局域網（LAN）內部。未來可整合 Overlay Network 技術（如 Tailscale / WireGuard 與 Cloudflare Tunnels），建立跨地域、多個人叢集間之安全 Mesh 互聯拓撲，並導入基於 BBR 演算法之動態頻寬感知機制，使異地朋友或跨校實驗室間能安全地共享閒置算力。
